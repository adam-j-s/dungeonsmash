But we also have a perform attack function in both weapon_base and player?

Yes, you're right - both the weapon_base.gd and player.gd files have perform_attack() functions, which is contributing to the issue. Let me clarify how these should interact:

Function Responsibilities
Player's perform_attack(): This is called when the player presses the attack button. It should handle player state (can_attack, is_attacking) and then delegate to the weapon.
Weapon's perform_attack(): This is called by the player's function and handles the actual attack execution, including cooldown timing.
How To Fix
The issue is that both functions are trying to manage cooldown, creating redundant timers. Here's how to fix them:
